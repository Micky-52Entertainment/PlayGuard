# Демо-плеебл

Маленький плеебл, чтобы попробовать PlayGuard без своего файла: три звезды, потом экран с кнопкой «Install».

| Файл | Зачем |
| --- | --- |
| `demo.html` | Плеебл без привязки к сети: кнопка открывает магазин через `window.open` |
| `builds/applovin/index.html` | Сборка для AppLovin (`mraid.open`) |
| `builds/unity/index.html` | Сборка для Unity Ads (`mraid.open`) |
| `builds/meta/index.html` | Сборка для Meta (`FbPlayableAd.onCTAClick`) |
| `demo-builds.zip` | Те же три сборки одним архивом |

Как попробовать:

1. **Один плеебл.** «Проверка» → перетащите `builds/applovin/index.html`. На шаге «Прохождение» впишите в поле Google Play `com.example.demo` — это приложение, на которое ведёт кнопка демо. Затем пройдите плеебл или нажмите «Быстрая проверка».
2. **Все сети сразу.** «Сборки» → перетащите `demo-builds.zip` (или папку `builds`). Программа сама поймёт, какая сборка для какой сети, и проверит все три.

Все проверки на демо проходят — так выглядит итог «Готов».
